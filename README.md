# BetterEeloo
An update to the Eeloo system to make it more interesting, and more inspired by Pluto

## Adds 2 new bodies
* Iziri, a very large moon. It pulls the barycenter way outside of Eeloo
* Ceivis, a tiny moon orbiting both Eeloo and Iziri.

## Changes to Eeloo
* Eeloo now has a proper atmosphere, 170 km high and very thin.
